## Difficult Feedback

**When to Use:** You need to give constructive feedback about a specific behavior or performance issue.

**Related Resources:**
- [Feedback Models](../leadership/feedback-models.md) - SBI, COIN, Radical Candor frameworks
- [Difficult Conversations](../leadership/difficult-conversations.md)

**The Prompt:**
```
I need to give difficult feedback to [team member name] about [specific behavior or issue].

Context:
- The behavior/issue: [describe what happened]
- Impact: [how this affects the team, project, or others]
- This is [first time / recurring pattern]
- Our relationship: [good working relationship / some tension / new team member]

Using the SBI (Situation-Behavior-Impact) model, help me structure this feedback conversation. Include:
1. Opening statement
2. Specific situation and behavior
3. Impact on the team/project
4. What I'd like to see instead
5. How to invite dialogue
6. Potential reactions and how to handle them

Refer to the feedback models in my knowledge base for frameworks.
```

**Expected Output:**
- Structured feedback script using SBI or COIN framework
- Prepared responses for defensive reactions
- Clear description of desired behavior change

**Follow-Up Actions:**
- Schedule 1:1 meeting
- Practice delivery
- Document the conversation
- Set follow-up check-in

## Underperformance Intervention

**When to Use:** A team member is consistently underperforming and you need to address it.

**Related Resources:**
- [Underperformance](../leadership/underperformance.md) - Root cause analysis and intervention frameworks
- [Performance Improvement Plans](../leadership/performance-improvement-plans.md)

**The Prompt:**
```
[Team member name] is underperforming in [specific area].

Details:
- Specific performance issues: [list observable issues]
- Duration: [how long this has been happening]
- Previous conversations: [none / informal / formal]
- Context: [any known personal issues, team changes, etc.]

Help me:
1. Analyze potential root causes using the 5 categories from the underperformance guide (Skill, Will, Role Fit, Environmental, Personal)
2. Determine the appropriate intervention level (coaching, formal conversation, PIP)
3. Create an action plan with specific, measurable goals
4. Plan the conversation script
5. Identify support mechanisms and timeline

Reference the underperformance and PIP guides in my knowledge base.
```

**Expected Output:**
- Root cause analysis
- Intervention strategy (coaching vs formal)
- Specific improvement goals with timeline
- Conversation script
- Support plan

**Follow-Up Actions:**
- Schedule formal conversation
- Document performance issues
- Create improvement plan
- Set check-in cadence
- Involve HR if needed

## Conflict Resolution

**When to Use:** Two team members have a conflict that's affecting team dynamics.

**Related Resources:**
- [Conflict Resolution](../leadership/conflict-resolution.md)
- [Difficult Conversations](../leadership/difficult-conversations.md)

**The Prompt:**
```
I need to mediate a conflict between [person A] and [person B].

Situation:
- The conflict: [describe the disagreement or tension]
- Observable impacts: [how it's affecting the team]
- How you learned about it: [directly from them / observed / reported by others]
- Relationship history: [previously worked well / always had tension / new collaboration]

Help me:
1. Prepare for individual conversations with each person
2. Create a mediation plan for bringing them together
3. Identify the type of conflict (task, process, relationship, values)
4. Develop ground rules for the mediation session
5. Plan how to move toward resolution
6. Identify follow-up actions to prevent recurrence

Reference the conflict resolution guide in my knowledge base.
```

**Expected Output:**
- Individual conversation scripts
- Mediation session plan
- Ground rules
- Resolution approach based on conflict type
- Follow-up plan

**Follow-Up Actions:**
- Schedule individual conversations
- Conduct mediation session
- Document agreements
- Monitor relationship going forward

## Recognition & Celebration

**When to Use:** You want to recognize someone's contribution or celebrate team success.

**Related Resources:**
- [Recognition](../leadership/recognition.md)

**The Prompt:**
```
I want to recognize [team member / team] for [specific achievement or contribution].

Details:
- What they did: [specific actions or results]
- Impact: [how this helped the team, company, customers]
- Recognition preference: [public / private / uncertain]
- Level of achievement: [above and beyond / consistently great work / important milestone]

Help me:
1. Choose the appropriate recognition method (public praise, 1:1 acknowledgment, formal award, etc.)
2. Craft a specific, meaningful recognition message
3. Determine if any tangible reward is appropriate
4. Plan the delivery for maximum impact
5. Consider team celebration if applicable

```

**Expected Output:**
- Recognition method recommendation
- Specific recognition script highlighting impact
- Delivery plan
- Any follow-up actions

**Follow-Up Actions:**
- Deliver recognition
- Document for performance review
- Consider team celebration
- Share with leadership if appropriate

## Career Development Conversation

**When to Use:** A team member wants to discuss career growth or asks about promotion.

**Related Resources:**
- [Career Development](../leadership/career-development.md)
- [GROW Model](../leadership/grow-model.md)
- [DevOps Career Ladder](../practices/devops-career-ladder.md)

**The Prompt:**
```
[Team member name] wants to discuss career growth / is asking about promotion to [target role/level].

Context:
- Current role: [title and level]
- Target: [what they want]
- Time in current role: [duration]
- Current performance: [meets expectations / exceeds / struggling]
- Key strengths: [list]
- Development areas: [list]

Using the GROW model, help me structure a career development conversation:
1. Goal: Clarify their career aspirations
2. Reality: Assess current skills and performance
3. Options: Identify development paths and opportunities
4. Way Forward: Create actionable development plan

Also reference the relevant career ladder (DevOps or general engineering) to provide specific expectations for the target level.
```

**Expected Output:**
- GROW-based conversation structure
- Gap analysis (current vs target level)
- Development plan with specific actions
- Timeline and milestones
- Honest assessment of promotion readiness

**Follow-Up Actions:**
- Create written development plan
- Identify stretch opportunities
- Schedule regular check-ins
- Update in next 1:1 agenda

## Performance Review Preparation

**When to Use:** You need to write a performance review for a team member.

**Related Resources:**
- [Performance Reviews](../leadership/performance-reviews.md)
- [Feedback Models](../leadership/feedback-models.md)

**The Prompt:**
```
I need to write a performance review for [team member name] covering [time period].

Information:
- Role: [title and level]
- Key accomplishments: [list major achievements]
- Areas of growth: [where they improved]
- Development areas: [where they need to improve]
- Team feedback: [any peer feedback or 360 data]
- Goals from last review: [previous goals and progress]
- Overall performance: [exceeds / meets / below expectations]

Help me write a comprehensive performance review that:
1. Provides specific examples (not generalities)
2. Balances strengths and development areas
3. Is fair and actionable
4. Sets clear expectations for next period
5. Includes concrete goals

Reference the performance review guide for structure and best practices.
```

**Expected Output:**
- Structured performance review with specific examples
- Balanced assessment
- Clear goals for next period
- Talking points for review conversation

**Follow-Up Actions:**
- Schedule review meeting
- Prepare for two-way conversation
- Document review in system
- Create development plan if needed

## Delegation Decision

**When to Use:** You need to decide what to delegate and to whom.

**Related Resources:**
- [Delegation](../leadership/delegation.md)

**The Prompt:**
```
I need to delegate [task/responsibility] but I'm not sure how or to whom.

Details:
- The task: [describe what needs to be done]
- Current owner: [you / someone else / nobody]
- Urgency: [timeline]
- Complexity: [high / medium / low]
- Risk if done wrong: [consequences]
- Potential delegates: [list team members with their experience levels]

Help me:
1. Determine the appropriate delegation level (1-7 scale from delegation guide)
2. Choose the right person based on their skills and development needs
3. Structure the delegation conversation
4. Set up appropriate oversight and check-ins
5. Avoid common delegation pitfalls (reverse delegation, micromanagement)

Reference the delegation guide for the 7 levels of delegation.
```

**Expected Output:**
- Recommended delegation level (1-7)
- Best person to delegate to with rationale
- Delegation conversation script
- Check-in plan
- Success criteria

**Follow-Up Actions:**
- Have delegation conversation
- Document expectations
- Schedule check-ins
- Resist urge to take back

## Handling Burnout Signs

**When to Use:** You notice signs of burnout in a team member or yourself.

**Related Resources:**
- [Burnout Prevention](../heuristics/burnout-prevention.md)
- [One-on-Ones](../leadership/one-on-ones.md)

**The Prompt:**
```
I'm noticing potential burnout signs in [team member name / myself].

Observable signs:
- [list specific behaviors: withdrawal, irritability, missed deadlines, etc.]
- Duration: [how long you've noticed this]
- Recent context: [major project, long hours, personal issues, etc.]
- Previous energy level: [normally high energy / always stressed / etc.]

Help me:
1. Assess whether these are burnout signs vs something else
2. Plan a supportive conversation (if team member) or self-reflection (if me)
3. Identify immediate actions to reduce stress
4. Create a recovery plan
5. Identify systemic issues that may be contributing

Reference the burnout prevention guide for warning signs and interventions.
```

**Expected Output:**
- Burnout assessment
- Conversation approach (empathetic, supportive)
- Immediate relief actions (time off, reduced load, etc.)
- Long-term prevention strategy
- Systemic changes if needed

**Follow-Up Actions:**
- Have supportive conversation
- Adjust workload immediately
- Address systemic issues
- Monitor recovery
- Regular check-ins

## First-Time Manager Transition

**When to Use:** You're promoting an IC to a management role or coaching someone through this transition.

**Related Resources:**
- [Delegation](../leadership/delegation.md)
- [One-on-Ones](../leadership/one-on-ones.md)
- [Feedback Models](../leadership/feedback-models.md)

**The Prompt:**
```
[Person name] is transitioning from IC to engineering manager [or I am making this transition].

Context:
- Previous role: [IC level and experience]
- Team they'll manage: [size, context, any former peers?]
- Management experience: [none / informal leadership / project lead]
- Strengths: [technical skills, relationships, etc.]
- Concerns: [managing former peers / giving feedback / time management]

Help me create a transition plan covering:
1. First 30-60-90 days priorities
2. Key management skills to develop immediately
3. How to navigate common first-time manager challenges
4. Setting up effective 1:1s
5. Learning to delegate technical work
6. Managing former peers if applicable

Reference relevant leadership guides (1:1s, feedback, delegation) for frameworks.
```

**Expected Output:**
- 30-60-90 day plan
- Priority skills to develop
- Common pitfall warnings
- Resource list for learning
- Support structure

**Follow-Up Actions:**
- Set up regular coaching sessions
- Schedule training
- Create 1:1 structure
- Build peer network of other managers

## Remote/Hybrid Team Challenge

**When to Use:** You're facing challenges specific to remote or hybrid team management.

**Related Resources:**
- [Remote/Hybrid Teams](../leadership/remote-hybrid-teams.md)
- [One-on-Ones](../leadership/one-on-ones.md)
- [Psychological Safety](../practices/psychological-safety.md)

**The Prompt:**
```
I'm managing a [fully remote / hybrid] team and facing this challenge: [specific issue].

Team context:
- Team size: [number]
- Locations/timezones: [distribution]
- Office policy: [fully remote / hybrid schedule / office + remote mix]
- Specific challenge: [communication / collaboration / team bonding / visibility / etc.]
- Current tools: [Slack, Teams, Zoom, etc.]

Help me:
1. Diagnose the root cause of this remote/hybrid challenge
2. Identify best practices for this specific issue
3. Create an action plan with specific tactics
4. Set up rituals or structures to prevent recurrence
5. Measure improvement

Reference the remote/hybrid teams guide for strategies.
```

**Expected Output:**
- Root cause analysis
- Best practices for your specific challenge
- Actionable tactics
- Team rituals or structures
- Success metrics

**Follow-Up Actions:**
- Implement new practices
- Gather team feedback
- Iterate based on what works
- Share learnings with peer managers
