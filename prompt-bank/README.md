# Prompt Bank

## Overview

This prompt bank provides **ready-to-use prompts** that leverage your engineering management knowledge base. Instead of reading through guides when you need help, use these prompts to quickly access relevant frameworks and guidance for specific situations.

## How to Use This Prompt Bank

### 1. Find Your Scenario
Browse the categories below to find a prompt that matches your current situation.

### 2. Customize the Prompt
Copy the prompt and fill in the specifics from your context (names, details, etc.).

### 3. Use with AI or Self-Reflection
- **With AI Assistant:** Paste the prompt to get guidance based on your knowledge base
- **Self-Reflection:** Use as a thinking framework to work through the situation yourself

### 4. Reference the Linked Resources
Each prompt links to relevant resources for deeper reading.

## Prompt Template Structure

Each prompt in this bank follows this structure:

```markdown
## Prompt Name

**When to Use:** [Specific scenario]

**Related Resources:**
- [Link to relevant guide]
- [Link to relevant framework]

**The Prompt:**
[Copy-paste ready prompt with [placeholders] to customize]

**Expected Output:**
[What you should get from using this prompt]

**Follow-Up Actions:**
[Common next steps after using the prompt]
```

## Contributing to the Prompt Bank

As you encounter new scenarios, add prompts following the template above. Keep them:
- **Specific** - Target a clear scenario
- **Actionable** - Include all context needed
- **Referenced** - Link to relevant resources
- **Tested** - Only add prompts you've actually used

## Tips for Effective Prompt Use

1. **Be Specific:** Fill in all [placeholders] with real details
2. **Add Context:** Include relevant background information
3. **Reference Resources:** Check the linked guides for deeper understanding
4. **Iterate:** If the output isn't helpful, refine the prompt with more context
5. **Document Learnings:** Update prompts based on what works
