# Performance Improvement Plans (PIPs)

A guide to structured performance management when standard feedback isn't working.

## What is a PIP?

**Performance Improvement Plan:** A formal, documented process to address performance issues with:
- Clear performance problems documented
- Specific expectations for improvement
- Defined timeline (typically 30-90 days)
- Regular check-ins and feedback
- Consequences if not successful (usually termination)

**Purpose:**
- Give employee clear chance to improve
- Protect company legally
- Document performance issues
- Set unambiguous expectations

**Reality:** Most PIPs end in termination (60-80%). They're often the last step before firing, not the first.

## When to Use a PIP

### Use a PIP When

✓ **Multiple feedback conversations haven't worked**
- You've had 3+ discussions about the same issues
- Clear expectations were set
- Reasonable time given to improve
- No meaningful change

✓ **Performance is significantly below bar**
- Affecting team or projects materially
- Can't continue indefinitely
- Clear gap to expectations

✓ **Issues are behavioral, not circumstantial**
- Not a temporary situation (illness, family emergency)
- Pattern across time
- Within their control to fix

✓ **You've given them tools and support**
- Resources provided
- Training offered
- Obstacles removed
- Still not improving

✓ **Company process requires it**
- HR or legal requirement
- Need documentation trail

### Do NOT Use a PIP For

✗ **First-time feedback** - Have conversations first
✗ **Temporary life situations** - Give them space (leave if needed)
✗ **Personality conflicts** - Address the behavior, not the person
✗ **Layoffs/budgets** - PIP is for performance, not headcount reduction
✗ **Diversity issues** - Don't use PIP to push out protected classes (legal risk)
✗ **Revenge or punishment** - This should be about improvement, not punishment

## Before Starting a PIP

### Checklist

**Have you:**
- [ ] Had multiple documented feedback conversations?
- [ ] Given clear, specific expectations?
- [ ] Provided adequate time and resources?
- [ ] Documented everything?
- [ ] Consulted with HR?
- [ ] Consulted with your manager?
- [ ] Considered alternatives (role change, transition out)?
- [ ] Checked for legal concerns (protected classes)?

**If you haven't checked all boxes, don't start a PIP yet.**

### Consult HR First

**Before writing the PIP:**
- Run it by HR
- Get template/format
- Understand company process
- Discuss legal considerations
- Align on timeline
- Determine check-in cadence

**HR should be involved in:**
- PIP creation
- Delivery meeting
- Check-in meetings
- Final decision

### Consider Alternatives

**Sometimes PIP isn't the answer:**

**Role change:**
- Maybe wrong role, not wrong person
- Different team or focus area
- Reset expectations in new context

**Managed transition:**
- Give them time to find new job
- Provide references
- Exit on good terms
- Severance consideration

**Immediate termination:**
- Egregious behavior
- Fraud, harassment, violence
- Skip the PIP

## Creating the PIP

### Structure

**Standard PIP document includes:**

1. **Introduction & Context**
   - Why we're here
   - Brief history
   - Purpose of PIP

2. **Specific Performance Issues**
   - Concrete examples with dates
   - Expected vs actual
   - Impact of issues

3. **Expected Improvements**
   - Clear, measurable goals
   - Specific behaviors needed
   - Success criteria

4. **Support & Resources**
   - What you'll provide
   - Training, tools, time
   - Who can help

5. **Timeline & Milestones**
   - Length of PIP (30/60/90 days)
   - Check-in schedule
   - Key milestones

6. **Consequences**
   - What happens if successful
   - What happens if not (usually termination)

7. **Acknowledgment**
   - Signature lines
   - Date
   - Understanding of terms

### Writing the PIP: Example

```
PERFORMANCE IMPROVEMENT PLAN

Employee: [Name]
Role: [Title]
Manager: [Your Name]
Date: [Date]
PIP Period: [Start] - [End] (60 days)

1. CONTEXT

Since joining the team in [date], we've had ongoing conversations about performance concerns. Despite multiple discussions (on [date], [date], and [date]) and clear feedback, the following issues persist. This Performance Improvement Plan is designed to provide you with a clear framework for improvement.

2. PERFORMANCE ISSUES

Issue 1: Missed Deadlines
- Expected: Deliver committed work on agreed timelines, or communicate blockers proactively
- Actual: 7 of last 10 sprints included missed deadlines with no advance notice
  * Example: User authentication feature (due March 15) delivered March 29
  * Example: Dashboard refactor (due April 1) still incomplete as of April 20
- Impact: Team unable to plan dependent work, stakeholders losing confidence

Issue 2: Code Quality
- Expected: Code passes automated tests, follows style guide, handles error cases
- Actual: 60% of PRs require multiple revision rounds for basic issues
  * Example: PR #234 had failing tests, no error handling, 15 style violations
  * Example: PR #267 caused production bug due to missing null check
- Impact: Increased review time, production bugs, technical debt

3. IMPROVEMENT EXPECTATIONS

By the end of this 60-day period, you must:

Goal 1: On-Time Delivery
- Complete 100% of committed sprint work on time
- If blocked, communicate in standup + async update same day
- Success: 8/8 sprints with all committed work completed on agreed dates

Goal 2: Code Quality
- All PRs have:
  * Passing automated tests
  * No critical or high-priority linter violations
  * Appropriate error handling
  * Clear PR description
- Success: 90% of PRs approved within 2 review rounds

Goal 3: Proactive Communication
- Daily standup updates
- Weekly progress summary to manager
- Immediate escalation if blocking issue arises
- Success: No surprises; manager always has current status

4. SUPPORT PROVIDED

I will provide:
- 30-minute weekly 1:1s (every Monday)
- Pairing session availability (2 hours/week)
- Code review best practices doc
- Access to [Training Resource]
- Clear sprint planning with realistic commitments

5. TIMELINE & CHECK-INS

Week 2: First check-in, assess initial progress
Week 4: Mid-PIP review, adjust if needed
Week 6: Second mid-PIP review
Week 8: Final assessment

6. OUTCOMES

Successful Completion:
If you meet all stated goals, you will continue in your role with regular performance management.

Unsuccessful Completion:
If goals are not met, your employment will be terminated.

7. ACKNOWLEDGMENT

I understand the expectations outlined in this Performance Improvement Plan and the consequences of not meeting them.

Employee Signature: _________________ Date: _______
Manager Signature: _________________ Date: _______
HR Signature: _____________________ Date: _______
```

### Writing Tips

**Be specific:**
❌ "Communication needs improvement"
✓ "Missed deadlines must be communicated in standup the day they're discovered"

**Be measurable:**
❌ "Better code quality"
✓ "90% of PRs approved within 2 review rounds; all PRs have passing tests"

**Be achievable:**
- Don't set them up to fail
- Goals should be hard but realistic
- If you don't think they can do it, don't do a PIP

**Be fair:**
- Document only facts and examples
- No emotional language
- No surprises (should've been discussed)
- Provide adequate support

## Delivering the PIP

### The Delivery Meeting

**Who should be there:**
- You (manager)
- Employee
- HR representative
- Possibly your manager

**Setting:**
- Private room
- End of day/week preferred
- 30-60 minutes blocked
- Have tissues available

**What to bring:**
- Printed PIP document (2 copies)
- Timeline document
- Contact info for resources

### The Conversation

**Opening (direct):**
"Thank you for meeting. I need to let you know that we're putting you on a formal Performance Improvement Plan. [HR person] is here as well. I know this is serious and I want to walk you through what this means."

**Walk through the document (15 min):**
- Read through each section
- Don't rush
- Allow them to process
- Answer questions
- Be clear about expectations and consequences

**Acknowledge emotions (5 min):**
- "I know this is difficult to hear"
- "Take your time"
- Let them react
- Don't apologize for the decision, but empathize with difficulty

**Next steps (5 min):**
- Sign the document
- Explain check-in schedule
- Clarify support available
- Answer procedural questions

**Close:**
"I want to be clear: I want you to succeed in this. I'm providing support and clear expectations. It's up to you to meet them. Do you have any questions?"

### Expect Different Reactions

**Shock/Denial:**
"I had no idea things were this bad"
→ "We've discussed these issues on [dates]. This is the formal next step."

**Anger:**
"This is unfair!"
→ Stay calm. "I understand you're upset. Here are the facts: [examples]."

**Acceptance:**
"I understand. I'll work on this."
→ "I appreciate that. Let's start with [first goal]."

**Defiance:**
"Fine, I'll just leave then."
→ "That's your choice. If you want to improve and stay, here's how. If you want to resign, we can discuss that with HR."

**Resignation:**
"I'll just look for another job."
→ "You're free to do that. While you're here, these expectations still apply."

## Managing the PIP Period

### Check-In Meetings

**Weekly 1:1s:**
- Review goals progress
- Document everything in writing
- Provide specific feedback
- Note improvements AND continued issues
- Keep notes for every conversation

**Sample check-in notes:**
```
PIP Check-in - Week 2
Date: [Date]
Attendees: [Names]

Progress:
✓ Goal 1 (On-time delivery): Both sprints on time this week
⚠ Goal 2 (Code quality): PR #234 had test failures, took 4 review rounds
✗ Goal 3 (Communication): Did not communicate blocker until standup next day

Discussion:
- Praised on-time delivery improvement
- Reviewed code quality checklist before submitting PR
- Clarified expectation: "blocked" means update me same day, not wait for standup

Action items:
- [Name] will use PR checklist
- [Name] will set daily 4pm reminder to send status if blocked

Next check-in: [Date]

Overall assessment: Some progress but code quality and communication still need work.
```

### Documenting Everything

**Keep detailed records:**
- All 1:1 notes
- Email communications
- Examples of work (PRs, docs)
- Peer feedback
- Incidents

**Why it matters:**
- Legal protection
- Fair assessment
- Clear decision making
- Reference if they contest

### Adjusting if Needed

**If circumstances change:**
- Personal emergency → Pause PIP
- Scope was wrong → Adjust with HR approval
- Making great progress → Continue to completion anyway

**Don't:**
- Remove PIP early without HR
- Extend timeline without reason
- Lower bar mid-PIP

## Ending the PIP

### Scenario 1: Successful Completion

**If they met all goals:**

```
PIP Completion - Successful

After 60 days on the Performance Improvement Plan, [Name] has successfully met all stated goals:

✓ Goal 1: 8/8 sprints with on-time delivery
✓ Goal 2: 95% of PRs approved within 2 rounds, all had passing tests
✓ Goal 3: Proactive communication maintained throughout period

[Name] will continue in their role with regular performance management. We'll continue to monitor these areas in our regular 1:1s.

Congratulations on the improvement.
```

**Meeting:**
- Acknowledge their hard work
- Reinforce expectations continue
- Set up ongoing check-ins
- Remove PIP designation
- Celebrate the win

**Important:** Keep close eye on performance post-PIP. Some people revert.

### Scenario 2: Partial Improvement

**Some improvement but goals not fully met:**

**Options:**
1. **Extend PIP** (with HR approval) - Give more time
2. **End employment** - Goals weren't fully met
3. **Adjust role** - Maybe different role is better fit

**Consult HR and legal before deciding.**

### Scenario 3: No Improvement or Worsening

**If no meaningful progress:**

**Termination meeting:**
- Include HR
- Be direct and brief
- "After 60 days, the goals of your PIP have not been met. Your employment is ending effective today."
- Review logistics (final paycheck, benefits, return of equipment)
- Keep it professional and short

**Don't:**
- Argue or debate
- Get emotional
- Make it personal
- Leave room for negotiation

## Legal Considerations

### Protect Your Company

**Document thoroughly:**
- Every conversation
- Every example
- Every resource provided
- Timeline of events

**Be consistent:**
- Apply PIP criteria uniformly
- Don't PIP one person but not another for same issues
- Follow company process exactly

**Watch for discrimination:**
- Protected classes (age, race, gender, disability, etc.)
- If employee is in protected class, extra care with documentation
- Ensure performance issues are real and documented

**Involve HR:**
- They know the legal requirements
- They've seen these before
- They protect you and company

### Employee Rights

**They can:**
- Resign instead
- Dispute the PIP claims
- File complaint with HR
- Consult a lawyer
- Request accommodations (if disability related)

**They cannot:**
- Refuse to sign (signature means received, not agreement)
- Demand changes to PIP
- Force you to remove it

## Alternatives to PIP

### When PIP isn't right

**Option 1: Immediate Termination**
- Serious misconduct
- Clear performance bar not met
- Consult legal first

**Option 2: Managed Transition**
- "This role isn't working out. Let's find you something that fits better."
- Give them 30-90 days to find new job
- Provide references
- Severance package
- Part ways on good terms

**Option 3: Role Change**
- Move to different team
- Different responsibilities
- Fresh start with clear expectations

**Option 4: More Time with Support**
- Not PIP yet
- More coaching
- Clear 30-day checkpoint
- "If not better in 30 days, we'll do formal PIP"

## Emotional Toll on You

### PIPs are Hard

**For the employee:**
- Stressful and scary
- May affect their confidence
- Financial pressure
- Career concerns

**For you:**
- Emotionally draining
- Second-guessing yourself
- Relationship strain
- Time intensive

### Self-Care

**Remember:**
- You gave them chances
- Clear expectations help them
- Letting poor performance continue hurts team
- This is part of the job

**Support yourself:**
- Debrief with your manager
- Talk to peer managers
- Don't do this alone
- Therapy/coaching if needed

**Boundaries:**
- This is professional, not personal
- You can care about them AND hold standards
- Their reaction isn't your responsibility
- You're doing your job

## After Termination

### Team Communication

**If PIP ends in termination:**

```
Team announcement:

"I wanted to let you know that [Name] is no longer with the company as of [date]. Their work will be distributed as follows: [plan].

I can't share details about the decision, but I'm happy to discuss how we'll handle the transition and any concerns you have about the team."
```

**Don't:**
- Bad-mouth them
- Share PIP details
- Discuss reasons
- Let team gossip

**Do:**
- Be brief and professional
- Focus on transition plan
- Answer logistical questions
- Move forward

### Lessons Learned

**After each PIP:**
- What could I have done earlier?
- Was my feedback clear enough?
- Did I provide enough support?
- What will I do differently next time?

**Improve your process:**
- Better job descriptions
- Clearer expectations at hire
- More frequent feedback
- Earlier intervention

## PIP Prevention

### The Best PIP is No PIP

**Prevent need for PIPs by:**
- Hiring well (see [Hiring Guide](./hiring.md))
- Clear expectations from day one
- Regular, specific feedback
- Early intervention on issues
- Proper onboarding (see [Onboarding](./onboarding.md))
- Good 1:1s (see [1-on-1s](./one-on-ones.md))

**Address problems early:**
- Don't wait for review
- One-off issue → conversation same week
- Pattern → formal feedback conversation
- Multiple patterns → PIP consideration
